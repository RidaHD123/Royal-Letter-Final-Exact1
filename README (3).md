# Gull Vard Corporation — Royal Letter

رسالة ملكية · Royal Letter · Lettre royale · Koninklijke brief (AR / EN / FR / VL)

Static site — no build step. Everything the page needs is in this repository (fonts are self-hosted; no external requests).

## Files
- `index.html` — the letter (single self-contained page)
- `fonts.css` + `fonts/` — Amiri, Scheherazade New, Cinzel (SIL OFL licences included)
- `favicon.svg`, `404.html`, `.nojekyll`

## Publish (GitHub Pages)
Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / folder **/(root)** → Save.
The site goes live at `https://<username>.github.io/<repository>/` within a minute or two.
